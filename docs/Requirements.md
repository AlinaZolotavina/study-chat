## Quality Requirements

The criteria below describe observable results for implemented scenarios in the stated environment. Time limits apply to simulated time with normal browser timers.

| ID                        | Area                     | Requirement                                                                                                                                           |
| ------------------------- | ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| <a id="qr-001"></a>QR-001 | Reliability | Reject an event that does not match the current `chatId`, `assistantMessageId`, and `runId`. |
| <a id="qr-002"></a>QR-002 | Reliability | Keep a terminal result unchanged when late events arrive. |
| <a id="qr-003"></a>QR-003 | Reliability | Fail a stalled request with a timeout when its configured wait limit expires. |
| <a id="qr-004"></a>QR-004 | Reliability | End a request with a normalized error if the agent throws or its iterator ends without a terminal event. |
| <a id="qr-005"></a>QR-005 | Resources | Release timers and subscriptions when an operation completes or is cancelled. |
| <a id="qr-006"></a>QR-006 | Data integrity | Leave the original malformed storage record unchanged for the duration of the session. |
| <a id="qr-007"></a>QR-007 | Text integrity | Reconstruct the original Markdown by concatenating fragments exactly, without splitting Unicode code points. |
| <a id="qr-008"></a>QR-008 | Response time | Complete each prepared text scenario within 4 seconds with normal timers and maximum configured delays. |
| <a id="qr-009"></a>QR-009 | Response time | Complete a calculator request in under 3 seconds with maximum configured delays. |
| <a id="qr-010"></a>QR-010 | Response time | Keep diagram preparation between 2,500 and 3,500 ms after analysis. |
| <a id="qr-011"></a>QR-011 | Performance | Preserve the suggestions selector result when a draft or another chat's data changes. |
| <a id="qr-012"></a>QR-012 | Persistence | Debounce ordinary writes until 400 ms after the most recent change. |
| <a id="qr-013"></a>QR-013 | Persistence | Immediately save chat structure changes, response completion, consumed failures, and action-history expansion. |
| <a id="qr-014"></a>QR-014 | Safe rendering | Keep links with protocols other than HTTP(S) inactive. |
| <a id="qr-015"></a>QR-015 | Safe rendering | Reject images outside approved local `assets/` paths. |
| <a id="qr-016"></a>QR-016 | Safe rendering | Render messages without executing embedded HTML. |
| <a id="qr-017"></a>QR-017 | Accessibility | Support primary actions by keyboard and show visible focus. |
| <a id="qr-018"></a>QR-018 | Accessibility | Keep focus inside an open modal and return it to an available element when the modal closes. |
| <a id="qr-019"></a>QR-019 | Contrast | Provide at least 4.5:1 contrast for body text and placeholders. |
| <a id="qr-020"></a>QR-020 | Contrast | Provide at least 3:1 contrast for large text and informative borders, icons, and focus indicators. |
| <a id="qr-021"></a>QR-021 | Compatibility | Keep primary actions available without horizontal page overflow in Chrome at widths of 320, 390, 768, 1,024, and 1,440 px. |
| <a id="qr-022"></a>QR-022 | Scaling | Keep input and primary actions available at 200% zoom and in a short viewport. |
| <a id="qr-023"></a>QR-023 | Motion | Disable diagram animation, decorative motion, and smooth history scrolling when `prefers-reduced-motion` is enabled. |
| <a id="qr-024"></a>QR-024 | Learning accuracy | Solve the fixed equation as x = 21/4 = 5.25 and verify that both sides equal 24.5. |
| <a id="qr-025"></a>QR-025 | Testability | Reproduce the same text stream for identical inputs, configuration, and injected random source. |
| <a id="qr-026"></a>QR-026 | Resources | Release the temporary URL and download element after a download succeeds, fails, or is cancelled. |
| <a id="qr-027"></a>QR-027 | Deployment | Resolve a local image path relative to the deployment base path. |

Text contrast thresholds are based on [WCAG: Contrast (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html). The 3:1 threshold for informative borders, icons, and focus indicators is a project criterion. Manual accessibility checks are not a full WCAG audit.

| <a id="m-03"></a>M-03 | Send a suggestion | Type a draft and select a suggestion. One message pair appears, the draft is preserved, and clicking again does not create another request. |

| <a id="m-10"></a>M-10 | Confirm deletion | Cancel and confirm deletion of an active chat. Cancel preserves data; confirmation selects a neighbor and does not stop other chats. |
