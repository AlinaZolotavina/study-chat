## Изменённые решения

- Оркестрация собрана в одном requestExecutor вместо распределения по thunks и дополнительному middleware. Бизнес-реализация исполнителя запланирована на следующий этап.
- Генератор диаграмм заменён предоставленным изображением Архимеда с CSS blur; геометрия и отдельная модель схемы исключены.
- TypeScript закреплён на 6.0.3 по совместимости с typescript-eslint вместо автоматического выбора 7.x.
- По результатам npm audit добавлен временный override minimatch 11.0.4; проверены используемые API и работа линтера, чистая установка завершилась без уязвимостей.

Продуктовых тестов пока нет. По мере реализации запись дополняется фактическими изменениями и проверками.
