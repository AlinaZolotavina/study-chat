# LOM AI

Образовательный mock AI-чат: React 19, TypeScript 6, Vite 8, Redux Toolkit. Реализованы основа, модель чатов и исполнитель запросов; в UI пока стартовый экран. Учебные сценарии агента и интерфейс чата — следующие этапы.

## Запуск

Node.js 22.23.2 указан в .nvmrc, npm — 10.9.8. Версии пакетов закреплены точно и сохранены в package-lock.json.

```sh
npm ci
npm run dev
```

По умолчанию: http://127.0.0.1:5173. Если порт занят, Vite выберет следующий; актуальный адрес будет в консоли.

| Команда            | Действие                                         |
| ------------------ | ------------------------------------------------ |
| npm run check      | Typecheck, ESLint, форматирование, запуск Vitest |
| npm run build      | Проверка типов и сборка в dist                   |
| npm run preview    | Просмотр сборки на http://127.0.0.1:4173         |
| npm run test:watch | Vitest в режиме наблюдения                       |
| npm run format     | Форматирование исходников и конфигурации         |

Vitest выполняет unit и четыре integration-теста. Фабрика createAppStore создаёт независимый store с внедряемыми agent, now и createId; store.dispose() отменяет оставшиеся запросы. Команды send/retry/stop/create/delete находятся в src/features/chat/model. Без внедрённого агента отправка безопасно завершается нормализованной ошибкой; готовые mock-сценарии будут подключены отдельно.

TypeScript 6.0.3 выбран по совместимости с typescript-eslint. Временный override minimatch 11.0.4 закрывает [GHSA-g3hv-75wg-m249](https://github.com/advisories/GHSA-g3hv-75wg-m249); при обновлении линтера его нужно пересмотреть.

## Этапы реализации

Ориентир: один frontend-разработчик, 3 дня / около 24 часов; два дня оставляют мало резерва. Объём меняется по согласованию.

Статус: «Основа» и «Модель и исполнитель» выполнены. Проверены модель, инвариант пары сообщений, send/retry-селекторы, отмена/cleanup, timeout с частичным результатом, независимость чатов, удаление активного чата, неизвестные ID и недопустимые события; 103 теста (99 unit + 4 integration), типы/lint/форматирование и production build проходят.
